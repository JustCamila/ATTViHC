O que é o Grid?

O Grid é um sistema de layout bidimensional (linhas e colunas) que permite criar estruturas complexas de forma simples e organizada.

As propriedades principais são:

  • grid-template-columns — define as colunas (ex: grid-template-columns: 1fr 1fr 1fr; cria 3 colunas iguais);
  • grid-template-rows — define as linhas (ex: grid-template-rows: 100px 100px; cria 2 linhas fixas);
  • gap — define o espaçamento entre linhas e colunas.

Atividade Prática

Crie uma página simples contendo:

  • Um contêiner com display: grid;
  • Defina 3 colunas e 2 linhas com grid-template-columns e grid-template-rows;
  • Aplique gap para espaçar os itens;
  • Faça um dos elementos ocupar duas colunas com grid-column;
