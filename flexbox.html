O que é o Flexbox?

O Flexible Box Module, geralmente chamado de flexbox, foi projetado tanto como um modelo de layout unidimensional quanto como um método capaz de organizar espacialmente os elementos em uma interface, além de possuir capacidades avançadas de alinhamento. Com o Flexbox, conseguimos criar layouts flexíveis e responsivos sem precisar usar float ou position complexos.

Os valores principais são:

  • row — em linha (padrão);
  • column — em coluna;
  • row-reverse ou column-reverse — inverte a ordem.

Atividade Prática

Crie uma página simples contendo:

  • Um contêiner com display: flex;
  • Três caixas com cores diferentes;
  • Use justify-content para centralizar os elementos horizontalmente;
  • Use align-items para centralizar verticalmente;
  • Altere flex-direction para column e veja como o layout muda;
  • Adicione flex-wrap: wrap e mais caixas para testar o comportamento com quebra de linha.
